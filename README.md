# AI-POT 1급 강의별 1,600문항

추천: `index.html`을 브라우저로 열어 읽으세요. 강의 선택·검색·정답 숨기기·인쇄가 가능합니다. 정답과 해설은 기본적으로 문제 아래에 표시됩니다.

- 강의별 Markdown 16개: 각 100문항
- 통합 Markdown: 전체 1,600문항
- JSON: 재편집용 문제 데이터(정답 인덱스는 0부터 시작)

이기적 영진닷컴의 「AI-POT AI 프롬프트활용능력 1급(2027)」 재생목록에 있는 16개 강의의 제목과 한국어 자동 자막을 참고한 창작 학습 문제입니다. 각 강의 100문항, 총 1,600문항이며 모든 문항은 정답 하나를 고르는 4지선다입니다. 공식 기출문제나 출제기관의 검수를 받은 자료는 아닙니다.

각 강의의 핵심 개념을 개념 확인·사례 적용·오개념 수정·개념 비교의 네 방향으로 반복 학습하도록 구성했습니다. 같은 개념을 다른 질문으로 다시 다룹니다. 사례와 계산값은 학습을 위해 새로 만든 예시이며, 실습 강의의 문항도 실제 도구 실행 대신 조건 이해와 결과 판단을 평가합니다.

분석 근거는 영상의 자동 자막이며 화면 속 슬라이드와 조작 장면 전체를 직접 검토한 것은 아닙니다. 자막의 오인식 표현은 문맥에 맞게 정리했습니다. 관련 강의 시간은 복습할 구간의 대략적인 분 단위 위치입니다. 강의의 일부 부정확한 설명은 원 논문·공식 자료에 맞춰 보완했습니다. 특히 AlexNet의 대표 성과 연도는 2012년으로, PhotoGuard는 AI 이미지 편집 방어 기법으로 설명합니다. 파일 첨부 여부만으로 멀티모달을 판단하지 않습니다.

서비스 기능은 강의에서 소개한 기능의 역할을 기준으로 다룹니다. 변동되는 요금·이용 한도는 출제하지 않았습니다. 저작권 문항은 기본적인 확인 원칙을 묻고, 특정 행위에 대한 법률 판단을 단정하지 않습니다.
